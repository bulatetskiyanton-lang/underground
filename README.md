# Нижний Край

Игра за монстров: к вам в подземелье приходят герои, а ведёт всё старый лич на пенсии.

- **Экран** (`/screen.html`) — телевизор или компьютер: лич, 3D-кубики, монстры, код комнаты.
- **Пульт** (`/pad.html`) — телефон: создать монстра, говорить с личом голосом, бросать кубики.

## Что нужно в Cloudflare

Секреты воркера (Settings → Variables and Secrets):

| Имя | Зачем |
| --- | --- |
| `ANTHROPIC_API_KEY` | мозги лича и создание монстров |
| `ELEVENLABS_API_KEY` | голос лича и распознавание речи с телефона |

Без ключей сайт открывается, но лич молчит: на первом экране видно, чего не хватает.

Номер голоса лича (`ELEVENLABS_VOICE_ID`) прописан в `wrangler.jsonc`, отдельным секретом его добавлять не нужно.

Необязательные переменные: `LICH_MODEL`, `VOICE_MODEL`, `STT_MODEL`.
